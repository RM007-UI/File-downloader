# دانلودر لینک مستقیم — GitHub Actions

این ابزار یک لینک مستقیم HTTP/HTTPS را می‌گیرد، فایل را روی GitHub Actions دریافت می‌کند و فایل اصلی را به‌صورت Asset در یک GitHub Release عمومی منتشر می‌کند. خروجی یک لینک مستقیم عمومی GitHub است؛ فایل ZIP نمی‌شود.

## اجرا با گوشی

1. مخزن عمومی را باز کن: https://github.com/RM007-UI/File-downloader
2. وارد زبانه Actions شو.
3. گردش‌کار Direct Link Downloader را انتخاب کن.
4. روی Run workflow بزن.
5. لینک مستقیم فایل را در file_url وارد کن.
6. در صورت نیاز نام دلخواه را در output_filename بنویس؛ در غیر این صورت نام سرور استفاده می‌شود.
7. تأیید کن که مالک فایل هستی یا اجازه انتشار عمومی آن را داری.
8. از گزینه max_connections تعداد 4، 8، 12 یا 16 اتصال را انتخاب کن؛ مقدار پیشنهادی 8 است.
9. گزینه skip_tls_verification را فقط وقتی روشن کن که گواهی HTTPS میزبان خراب است و ریسک آن را می‌پذیری؛ در حالت عادی خاموش بماند.
10. اجرا را شروع کن.
11. ابزار ابتدا HTTP Range را آزمایش می‌کند. اگر سرور پشتیبانی کند، فایل با چند اتصال موازی دریافت می‌شود؛ در غیر این صورت خودکار به یک اتصال برمی‌گردد.
12. هنگام دانلود، حجم دریافت‌شده، کل، باقی‌مانده، درصد، سرعت و ETA نمایش داده می‌شود.
13. بعد از موفقیت، در Summary روی Download original file بزن.

## فرمت‌ها و محدودیت‌ها

- هیچ محدودیتی برای پسوند یا MIME type وجود ندارد؛ فایل به‌صورت بایت خام منتقل می‌شود. APK، ZIP، RAR، PDF، MKV، MP4، MP3، تصاویر، اسناد و سایر فرمت‌ها پشتیبانی می‌شوند.
- لینک باید مستقیم و عمومی HTTP یا HTTPS باشد؛ لینک صفحه وب، ورود به حساب، کوکی یا header سفارشی پشتیبانی نمی‌شود.
- مقصدهای شبکه داخلی، خصوصی و رزروشده رد می‌شوند؛ مقصدهای redirect هم بررسی می‌شوند.
- سقف هر فایل 1900 MiB است تا زیر محدودیت GitHub Release بماند.
- فایل در Release عمومی منتشر می‌شود؛ هر کسی که لینک را داشته باشد می‌تواند آن را دریافت کند.
- لینک موقت/امضاشده باید تا زمان اجرای Workflow معتبر باشد.
- بررسی گواهی TLS به‌صورت پیش‌فرض روشن است. گزینه skip_tls_verification فقط برای همان اجرا بررسی گواهی و نام میزبان را خاموش می‌کند؛ در این وضعیت مهاجم می‌تواند فایل را در مسیر تغییر دهد. برای فایل اجرایی مثل APK این گزینه را روشن نکن، مگر اینکه منبع فایل را از راه دیگری تأیید کرده باشی.

## انتشار عمومی

چون خروجی عمومی است، فقط فایل‌هایی را منتشر کن که حق انتشار عمومی آن‌ها را داری. مسئولیت رعایت حق نشر و شرایط میزبان بر عهده منتشرکننده است.

## ساختار پروژه

- tools/downloader.py: دانلودر چنداتصالی با HTTP Range، ادامه/تلاش مجدد بخش‌های ناموفق، پشتیبانی از همه فرمت‌ها و SHA-256
- .github/workflows/direct-link-downloader.yml: اجرای دستی و ساخت Release عمومی
- .github/workflows/tests.yml: تست‌های آفلاین

## سرعت دانلود

- ابتدا سرور با درخواست `Range: bytes=0-0` آزمایش می‌شود.
- در صورت پشتیبانی، فایل به بخش‌های جدا تقسیم و با حداکثر 16 اتصال دریافت می‌شود.
- مقدار پیش‌فرض پیشنهادی 8 اتصال است؛ می‌توانی 4، 8، 12 یا 16 را انتخاب کنی.
- اگر سرور Range را نپذیرد، دانلود به روش تک‌اتصالی برمی‌گردد.
- هر بخش تا 3 بار تلاش مجدد دارد؛ اگر دانلود موازی شکست بخورد، ابزار یک بار به روش تک‌اتصالی برمی‌گردد.
- چنداتصالی سرعت را تضمین نمی‌کند؛ محدودیت میزبان، شبکه و GitHub Actions همچنان مؤثر است.
